# Software Install — установка приложений и игр

Установка — это изменение системы, а не просто команда. Сначала детали и
план, потом явное согласие, только затем действия. Не угадывай название,
версию, источник и папку.

## 1. Железные правила

1. **Без согласия — ни шага.** Не скачивай, не запускай установщик и не
   меняй систему, пока пользователь не ответил «ставь», «устанавливай» или
   другим явным согласием именно на показанный план.
2. **Сначала выясни, что ставим.** Точное название, приложение или игра,
   версия/издание, источник, лицензия, папка, ярлык, запуск после установки.
3. **Не выдумывай успех.** Установка подтверждается наличием программы,
   версией, запуском процесса или записью в списке winget.
4. **Неофициальный файл — всегда проверка.** Перед запуском установщика,
   exe или папки игры из неофициального источника вызови `scan_file`.
   Официальный файл проверяй, если пользователь прямо об этом попросил, или
   если не сходится цифровая подпись. Угроза найдена — стоп, файл не запускать.
5. **UAC не обходить.** Сначала пробуй установку для пользователя. Если нужен
   администратор — предупреди и дай пользователю подтвердить окно Windows.
6. **Никаких «кряков» и пиратских сборок по своей инициативе.** Если
   пользователь дал свой файл — проверь его и запусти. Если игры нет в
   официальном магазине, предложи официальный сайт или файл пользователя.
7. **Не отключай Defender, не добавляй исключения и не сохраняй пароль.**
   Даже если установщик просит «разрешить всё» — это повод остановиться.
8. **Установка Windows-приложений возможна только там, где они есть.**
   Если Немуся запущена в Docker/VPS или без интерактивного стола, winget,
   UAC и окна установщиков недоступны. Скажи об этом честно и предложи
   варианты, а не притворяйся, что приложение установлено.

## 2. Что уточнить до плана

Задавай только то, чего нет в запросе. Достаточно одного короткого раунда.

- **Что именно:** точное название, версия или издание. Для игры — название
  и магазин/платформа.
- **Источник:** winget, официальный сайт, Steam, Epic, уже скачанный файл.
  Если пользователь говорит «любой» — предложи самый безопасный и назови
  альтернативу.
- **Лицензия:** бесплатно, уже куплено, нужна покупка. Покупку и вход в
  аккаунт пользователь выполняет сам; ты открываешь магазин и ждёшь.
- **Место:** куда ставить. По умолчанию — стандартная папка программы;
  для portable — `%LOCALAPPDATA%\Programs\<Название>` или папка пользователя.
- **Права:** можно ли вызвать UAC. По умолчанию сначала пробуй без админа.
- **Ярлык:** рабочий стол, меню «Пуск» или не нужен. По умолчанию — рабочий
  стол, если пользователь просил ярлык.
- **Запуск:** проверить сразу или оставить закрытым. Для игры достаточно
  проверить лаунчер/исполняемый файл, не оставляя игру открытой.
- **Старое:** если программа уже стоит — обновить, переустановить или
  оставить. Не удаляй данные без отдельного согласия.

Если пользователь уже всё указал — не переспрашивай, переходи к плану.

## 3. Разведка перед планом

Выполняй безопасные проверки, они не меняют систему:

```bat
:: winget: полный путь обязателен, иначе команда может не найтись
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" --version
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" search "<название>"
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" show --id <ID> --exact
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" list --id <ID> --exact
```

Ещё проверь:

- место на диске: `Get-PSDrive C | Select-Object Used,Free`;
- уже установлено: `winget list`, меню «Пуск», типовые папки;
- Steam: `Test-Path "C:\Program Files (x86)\Steam\steam.exe"`;
- Epic: `Test-Path "C:\Program Files\Epic Games\Launcher\Portal\Binaries\Win32\EpicGamesLauncher.exe"`;
- для официального установщика — страницу загрузки, версию, размер, подпись.

Не показывай пользователю сырые логи. В плане — только выводы.

## 4. План перед установкой

Покажи короткий план и остановись. Пример:

```text
Поняла: ставим <Название> <версия>.
• Источник: winget, ID <...>, издатель <...>
• Лицензия: бесплатно / уже куплено / нужна покупка
• Размер: <...>, на диске свободно <...>
• Куда: <папка>
• Права: без администратора / понадобится UAC
• Ярлык: рабочий стол / меню «Пуск» / не нужен
• Проверка: версия + запуск, затем закрою тестовый процесс
• После: <обновление / удаление старой версии / ничего>

Ставить? Напиши «ставь», и я начну.
```

Если установка требует покупки, отдельно скажи: «Игру нужно купить в
Steam/Epic; я открою страницу, покупку подтверждаешь ты». Не обещай
бесплатную установку платной игры.

## 5. Приложения через winget

Сначала ищи точный ID, не ставь по первому совпадению:

```bat
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" search "<название>"
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" show --id <ID> --exact
```

Проверь издателя, версию и источник. Если совпадений несколько — покажи
2–3 варианта с ID и спроси, какой нужен.

Установка без администратора:

```bat
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" install --id <ID> --exact ^
  --source winget --scope user --accept-package-agreements ^
  --accept-source-agreements
```

Если `--scope user` не поддерживается или установка не удалась — повтори без
`--scope user`, предупредив про возможный UAC. Не добавляй `--silent`, если
программа может требовать выбора компонентов; сначала попробуй обычный
установщик. Долгую установку запускай через `run_shell action=start` и
опрашивай `action=read`, а не жди одним вызовом.

После установки:

```bat
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" list --id <ID> --exact
```

## 6. Официальный установщик

1. Скачай только с домена производителя инструментом `download_file`. Он сам
   создаёт `data/downloads`, очищает имя файла, ограничивает размер и возвращает
   абсолютный путь, размер и SHA-256:

```text
download_file(url="https://производитель/.../setup.exe", filename="setup.exe")
```

   Не собирай `curl` с относительным путём: `run_shell` работает из workspace,
   а не из корня проекта, поэтому `data\downloads` там не существует.

2. Проверь подпись, используя **абсолютный путь из ответа** `download_file`:

```powershell
Get-AuthenticodeSignature "<путь из download_file>" |
  Select-Object Status,StatusMessage,@{n='Signer';e={$_.SignerCertificate.Subject}}
Get-FileHash "<путь из download_file>" -Algorithm SHA256
```

   SHA-256 из ответа инструмента сверь с `Get-FileHash`. Если подпись не
   `Valid` или издатель не совпадает — не запускай без отдельного
   подтверждения пользователя.

3. Проверь файл антивирусом, если пользователь прямо попросил об этом или
   если подпись не `Valid`:

```text
scan_file(path="<путь из download_file>")
```

Если `scan_file` вернул ошибку «угроза» — остановись. Не запускай файл, не
добавляй исключение, покажи пользователю вывод и предложи удалить загрузку.

4. Запусти установщик. Для `.exe`:

```powershell
Start-Process -FilePath "<путь из download_file>" -Wait
```

Для `.msi`:

```bat
msiexec.exe /i "<путь>" /qb
```

UAC-окно подтверждает пользователь. Если окно не появилось или установка
зависла — не убивай процесс сразу: проверь, не ждёт ли он ввода, и покажи
пользователю, что происходит.

## 7. Игры

### Steam

Найди `steam.exe` и открой установку по appid:

```powershell
Start-Process "C:\Program Files (x86)\Steam\steam.exe" `
  -ArgumentList "steam://install/<appid>"
```

AppID возьми из ссылки магазина `store.steampowered.com/app/<appid>/`.
Steam может показать свой диалог — это нормально, пользователь подтверждает.
Не пытайся обойти клиент Steam и не скачивай игру со сторонних сайтов.

### Epic Games

Epic не имеет надёжного тихого CLI-установщика. Открой лаунчер и страницу
игры, затем попроси пользователя подтвердить установку в клиенте. Не
выдумывай, что игра установилась, пока она не появилась в библиотеке.

### Standalone или свой exe

1. Уточни путь к файлу или папке игры.
2. Если файл скачан из неофициального источника — `scan_file` обязателен.
3. Сними блокировку с файла, если Windows пометил его как скачанный:

```powershell
Unblock-File -Path "<путь>"
```

4. Запусти игру или лаунчер. Для проверки достаточно, чтобы процесс
   запустился и не упал сразу; не оставляй игру открытой без просьбы.
5. Создай ярлык, если просили.

## 8. Ярлык

Рабочий стол:

```powershell
$desktop = [Environment]::GetFolderPath('Desktop')
$lnk = Join-Path $desktop '<Название>.lnk'
$ws = New-Object -ComObject WScript.Shell
$s = $ws.CreateShortcut($lnk)
$s.TargetPath = '<путь к exe>'
$s.WorkingDirectory = '<папка>'
$s.Save()
```

Меню «Пуск»: замени `Desktop` на `Programs`. Проверь, что `.lnk` создан, и
верни пользователю путь.

## 9. Проверка после установки

- Приложение: `winget list --id <ID> --exact` или наличие `.exe`/ярлыка.
- Запуск: `Start-Process -PassThru`, подожди 5–10 секунд, проверь
  `HasExited`. Если процесс сразу упал — покажи ошибку и не называй
  установку успешной.
- Игра: проверь лаунчер или исполняемый файл; не запускай тяжёлую игру
  без согласия.
- Ярлык: `Test-Path` для `.lnk`.
- Версия: `--version` или свойства файла, если доступны.

## 10. Обновление и удаление

Только по отдельной просьбе и после плана с подтверждением.

```bat
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" upgrade --id <ID> --exact
"%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe" uninstall --id <ID> --exact
```

Перед удалением уточни, сохранять ли данные и настройки. Не удаляй папки
вручную, если установщик умеет штатное удаление.

## 11. Отчёт

Коротко, без сырых логов:

```text
Готово: <Название> <версия>
Источник: <winget/сайт/Steam/файл>, <URL или ID>
Установлено в: <путь>
Проверка: <версия/запуск/процесс>
Антивирус: <чисто/не проверялось — почему>
Ярлык: <путь или не создавала>
Замечания: <UAC, покупка, старая версия, что осталось>
```

Если что-то не получилось — скажи, на каком шаге и почему, что уже
изменено и что безопасно сделать дальше. Не скрывай неудачу за словом
«готово».
